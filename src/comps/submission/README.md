## Submission Components

This folder contains all react-components used for sample submission. 

The sub-tabs are the following:
- New - starting a project includes receiving an unique identifier and entering specific informations about the experimental design.
The information that are beeing requested are fetched from the API. 
- Project - Overview of all projects fetched from the API. Notably, admins will be able to view all available projects while others will only be able to view their own projects. 
- Statistics 
- Help - useful information about the standard for submitting samples including a FAQ section. PLease note that the data are also fetched from the API. The reason 
for that is that this allows everyone to specifiy the information provided to the user in a single place (e.g. API)
